## ⚙️ Setup
1. Make a `.env` file in the main folder
2. Set `APPID` to your OpenWeatherMap API key in the .env file (`APPID=...`)
3. Run `python -m venv .venv` to set up venv
4. Activate venv (`.\.venv\Scripts\Activate.ps1` for Powershell)
5. Run `pip install -r requirements.txt`
6. Run `main.py`
